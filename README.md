# Kay Gijzen — Personal Website

Personal website, hosted at [kaygijzen.github.io](https://kaygijzen.github.io).

## Stack

Vite, React, TypeScript, Tailwind CSS

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Output is generated in `dist/`.

## Deployment

Automatically built and deployed to GitHub Pages via GitHub Actions on every push to `main`.
